4.Card move operation
Public synchronized int K720_SendCmd(byte MacAddr, byte[] p_Cmd, int CmdLen, String[]
RecordInfo);
Function：Device move operation function
parameter：【in】MacAddr Device address

【in】p_Cmd Command parameters
p_Cmd = “DC” Indicates moving to the pickup location
p_Cmd = “CP” Indicates recycling card to recycling box
p_Cmd = “DB” Indicates that the card is recycled to the card issuing

box [K750 exclusive command]
p_Cmd = “RS” Indicates card dispenser reset
p_Cmd = “BF" or "FC8" means front-end card
p_Cmd = “BG” Indicates that the front end is prohibited from

entering the card [invalidate "BF" or "FC8"]
p_Cmd = “FC6” Indicates moving to the sensor 2 position
p_Cmd = “FC7” Indicates moving to the card reading position
p_Cmd = “FC4” Indicates to move to the card-receiving position

[requires force to pull out the card]
p_Cmd = “FC0” Indicates moving to the outside of the bayonet [drop

from the bayonet]
p_Cmd = "LP"+0 means setting the LED to be always on, where 0

means the flashing frequency [0 is 0 in hexadecimal, not 0
in ASCII, pay attention to the distinction]

P_Cmd ="LF" means set LED off
P_Cmd = "BE" means set beeping
P_Cmd = "BD" means stop beeping
P_Cmd = “FD0” Indicates that the front-end automatic induction

card enters
P_Cmd = “FD1” Indicates that it is necessary to execute the

command through "BF" or "FC8" and enter the card at the
front end

P_Cmd = “FD2” Indicates that the reset operation is performed, and
the channel card does not act.

P_Cmd = “FD3” Indicates that the reset operation is performed, and
the channel card is returned to the card issuing box

P_Cmd = “FD4” Indicates that the reset operation is performed, and
the channel card is returned to the recycling box

【in】CmdLen Command parameter length [determined by p_Cmd, 2 or 3]
【out】RecordInfo Return data interaction record

Return value: 0 means success, other means failure, please refer to the error code at the bottom for details

Function：Get parameter setting information

StateInfo[0] = 0x01 Indicates that the front-end card needs to be

2.Move card interface
Public synchronized int K720_MoveCard(byte _PM);
Function：Card move operation [This interface will return after the action is completed or timed
out, which is the encapsulated action flow]
parameter：【in】_PM _PM = 0x30 Indicates that the card box is issued to the card

_PM = 0x33 Indicates moving the card to the recycling box
_PM = 0x34 Indicates that the card is moved to the card issuing box

Return value: 0 means success, other means failure, please refer to the error code at the bottom for details

Public synchronized int K720_RetainToCardBox(boolean flag, int EnterTimeOut, int TimeOut);
Function：Recycle the card to the card issuing box [the difference from K720_MoveCard is that the

reserved parameter can be set whether the card is inserted in the front or not]
parameter：【in】flag Do you need to enter the card from the front

flag = true means that the front-end card entry function will be
performed inside the interface, and the card can be inserted within the
EnterTimeOut time, otherwise it will return to the card entry timeout

flag=false means that it is necessary to ensure that there is a card in
the channel before recycling the card to the card issuing box,
otherwise it will return no card error

【in】EnterTimeOut Front-end card entry timeout time
14



【in】TimeOut The timeout period for recycling to the card box [does not include
the timeout period for incoming cards]

Return value: 0 means success, other means failure, please refer to the error code at the bottom for details

3.Get device status
Public synchronized int K720_CheckCardPosition(byte [] DeviceStatus, byte [] TransportStatus,
byte [] CardBoxStatus, byte [] RetainBoxStatus);
Function：Query device status [same function as K720_SensorQuery, the difference is that the
returned value is processed]
parameter：【out】DeviceStatus Return device status

DeviceStatus = 0x30 Indicates that the current action is idle
DeviceStatus = 0x31 Indicates equipment failure [reset

operation is required]
DeviceStatus = 0x32 Indicates that the card preparation failed
DeviceStatus = 0x33 Indicates that the card is being issued
DeviceStatus = 0x34 Indicates that the card is being collected
DeviceStatus = 0x35 Indicates an error in issuing the card
DeviceStatus = 0x36 Indicates a card error

【out】TransportStatus Return channel status
TransportStatus= 0x30 Indicates that the channel has
overlapping cards
TransportStatus= 0x31 Indicates that the channel is blocked
TransportStatus= 0x32 Indicates that there is a card in the card
reader
TransportStatus= 0x33 Indicates that the channel has no card
